# 自动化

本体自动化由有序步骤、事件触发、Fn 单击/双击绑定和运行管理组成。插件自定义动作/触发器不属于本轮扩展。

## 开关和触发

- 总开关控制事件触发和 Fn 绑定；关闭时取消当前运行及排队任务。仍可通过“运行”手动测试已启用的规则。
- 每条规则有独立启用开关。停用或删除规则会取消其运行和排队，并让对应 Fn 绑定回到默认行为；旧配置未声明该字段时保持启用。
- 支持电源适配器插入/断开、游戏开始/结束、Toolkit 启动完成、睡眠/休眠唤醒、锁屏和解锁。
- 启动事件每次程序初始化仅触发一次。唤醒事件在恢复休眠前性能模式之后触发，不在普通电源状态通知中触发；重复锁屏/解锁通知不重复执行。
- 电源和游戏事件是状态变化事件，不会仅因打开总开关就对当前状态补执行。

## 新增本体动作

| 动作 | 参数及规则 |
| --- | --- |
| 内屏分辨率 | 从当前内屏驱动提供的分辨率选择；尽量保持刷新率；15 秒内未确认会还原并停止后续步骤 |
| 内屏 DPI | 当前内屏支持的固定缩放档位；同样需要确认。锁屏时不执行显示变更 |
| 设置功耗参数 | 选择参数并填写整数，按当前 WMI / Intel MMIO / AMD / NVAPI 接口的单位和范围校验；真实读回及固件钳位沿用本体逻辑 |
| 功耗参数锁定 | 选择参数和锁定/解除/切换；锁定前需能读取参数，解除锁定不要求重新读取硬件 |
| 功耗 Beta 开关 | Intel MMIO、AMD ZenStates、NVAPI GPU：开启/关闭/切换；可用性检查和接受值重置与手动设置一致 |
| 启动时恢复上次背光 | 开启/关闭/切换该偏好，不在运行中反复强制背光 |

例如，先切换性能模式，再开启对应功耗 Beta、设置参数、锁定参数。步骤按列表顺序执行，参数单位必须与当前接口一致；AMD PBO 的 TDC/EDC 使用电流单位，而不是瓦数。

既有动作继续支持：GPU 模式与超频开关、强制关闭独显占用应用、风扇策略及曲线、固定转速普通/游戏状态、充电与供电、刷新率、护眼和色域、声音、键盘与触摸板、OSD、传感器记录、窗口操作、打开应用、键盘宏及小数秒延迟。

系统级自定义 DPI 会影响所有屏幕并要求注销，因此不提供无人值守动作。本轮也不新增关机、重启、任意脚本执行或驱动安装动作。已有 GPU 模式等需要重启的功能仍遵循本体原有行为。

## 执行与取消

- 同时仅执行一条规则，同一规则已在运行或排队时不重复排入；最多容纳 32 个运行/排队请求。
- 请求入队时复制步骤快照。编辑保存只影响下一次运行，不会修改正在执行的步骤列表。
- 保存及运行前预检参数，支持有限的 0–86400 秒延迟（含小数），拒绝 NaN/Infinity。执行时再次检查设备是否支持所选动作。
- 任一步失败会停止后续步骤。展开“自动化”卡片后，可在默认折叠的“运行记录”中查看当前步骤、排队状态、失败原因和最近结果；本次进程最多保留 20 条历史。记录不再占用独立卡片，“取消全部运行”仅在有运行或排队任务时显示。
- 可取消单条或全部任务；睡眠、退出和系统关机会取消队列。取消不强制中断已发出的硬件调用，也不自动撤销已完成动作；显示确认步骤除外，它会尝试还原未确认的修改。
- 当前不可用的显示选项仍保留在编辑器中，以免拔掉屏幕或改变环境时丢失已保存参数；运行时不可用则明确失败，不切换到外接主屏凑数。

所有新增动作、触发条件都需要用户主动添加。原有动作/触发器的数字编号保持不变。

自动化编辑器按 CPU 厂商显示功耗 Beta 动作：Intel 处理器仅显示 Intel MMIO，AMD 处理器仅显示 AMD ZenStates；未知厂商不显示这两项。NVAPI GPU Beta 保持显示，不随 CPU 厂商隐藏，执行时仍检查接口可用性。旧配置中不匹配当前 CPU 的步骤不会被删除，但运行前会拒绝执行并提示对应步骤。
